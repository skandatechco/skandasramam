Preconditions: migrations 1-5 + seed applied on **staging**; `pooja_days` copied; one admin user (in `admin_users`)
and one ordinary Auth user; `.env.local` points at staging; `PAYMENTS_LIVE` / `VITE_PAYMENT_QR_CONFIGURED` unset;
NODE_ENV not production (so the labelled TEST QR flow works). Use a fake phone/email.

Automated coverage today (all against PGlite / mocked clients): 7 DB suites (migrations, RLS and privileges,
